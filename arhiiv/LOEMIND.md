# Arhiiv

Vanad failid, mida rakendus enam ei kasuta. Midagi pole kustutatud — need on siin alles,
aga server neid välja ei näita (serveeritakse ainult `public/` kausta).

- `royal-lehed/` — vanad koopiad admini ja töötaja lehtedest (olid avalikult kättesaadavad aadressil /royal-lehed/…)
- `xseeria-admin.html` — vana X-seeria admin (kasutas serveri aadressi, mida enam pole). Aadress suunab nüüd /xseeria-haldus lehele.
- `kristo.html` — vana Kristo vaade. Aadress suunab nüüd /lidl-eesti lehele.
- `vana-juur/` — juurkaustas olnud vanad koopiad (tootaja.html, sw.js, manifest, ikoonid). Päris failid on `public/` kaustas.
